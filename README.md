## Cara Deploy Gratis ke Vercel
1. Upload repo ini ke Github
2. Buka vercel.com -> Login Github -> Import Absensi-Perangkat
3. Env Variable:
   WIFI_SSID=CIKA_NANAT
   ADMIN_PASSWORD=Ch@dast1936
4. Deploy -> Selesai

## Bot WA Gratis
- Buka /setting-bot -> Scan QR pakai HP Sekdes
- HP cukup internet ON (tidak wajib WiFi desa)
- Kalau HP offline, notif masuk antrian, kekirim pas online lagi
- Kalau offline >10 menit, dashboard muncul "Bot Offline" + notif lonceng web

## Ganti Setting (Bisa Kapan Saja)
- WiFi: /admin/setting -> WiFi Desa
- Password: /admin/setting -> Ganti Password
- Nama Repo: Github Settings -> Rename
